kakfa duplicaiton solution using lambda---

To solve the duplicate transaction issue, the most robust and standard solution is to build an idempotent service. This means your processing system can receive the same message multiple times but will only act on it once, effectively preventing duplicates.

We will implement this using an AWS Lambda function for processing and an Amazon DynamoDB table to track which transactions have already been seen.

The Solution: Lambda for Logic, DynamoDB for Memory
This architecture is a powerful pattern for creating resilient, serverless data pipelines.

Trigger: Each message from your Kafka topic (sainsburys.data.sc-sss.txns.receipts.v5) will trigger the Lambda function.

Deduplication Logic: For every message, the Lambda will:

Extract a unique business ID from the message payload (e.g., INV_TXNS_STG_ID).

Attempt to write this ID to a DynamoDB table using a conditional write, which only succeeds if the ID is not already present.

Outcome:

New Message: If the write to DynamoDB is successful, the Lambda executes your main business logic.

Duplicate Message: If the write fails because the ID already exists, the Lambda logs the duplicate and stops, preventing it from being processed again.

Detailed Implementation Steps ⚙️
Here is how to build this solution from scratch.

Step 1: Create a DynamoDB Table for Deduplication
This table will act as the "memory" for your service, storing the IDs of processed transactions.

Navigate to the DynamoDB service in the AWS Console.

Click Create table.

Table name: ProcessedTransactionIDs

Partition key: transactionId (Type: String)

Leave all other settings as default and click Create table.

(Recommended) After the table is created, select it, go to the Additional settings tab, and find the Time to Live (TTL) section. Click Turn on.

TTL attribute name: expirationTime

This will automatically delete old transaction records after a set time to manage costs and keep the table clean.

Step 2: Create an IAM Role for the Lambda Function
The Lambda function needs specific permissions to operate.

Navigate to the IAM service and create a new Role.

Select AWS service and Lambda as the use case.

Attach the necessary policies:

AWSLambdaBasicExecutionRole (for writing logs to CloudWatch)

AWSLambdaMSKExecutionRole (if using Amazon MSK as the trigger) or a similar policy for your Kafka event source.

Create a new inline policy to grant permission to the DynamoDB table. Give it a name like DynamoDBPutItemPolicy and use the following JSON, replacing the example ARN with your actual table ARN.

JSON

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "dynamodb:PutItem",
            "Resource": "arn:aws:dynamodb:eu-west-1:123456789012:table/ProcessedTransactionIDs"
        }
    ]
}
Give the overall role a name, like KafkaDeduplicationLambdaRole, and create it.

Step 3: Create the Deduplication Lambda Function
This function contains the core logic.

Navigate to the Lambda service and Create function.

Select Author from scratch.

Function name: kafka-transaction-deduplicator

Runtime: Python 3.12

Permissions: Choose Use an existing role and select the KafkaDeduplicationLambdaRole you just created.

Click Create function.

In the Code source editor, paste the following Python code:

Python

import boto3
import os
import json
import base64
from botocore.exceptions import ClientError
from datetime import datetime, timedelta, timezone

# Get config from Lambda environment variables
DYNAMODB_TABLE_NAME = os.environ['DYNAMODB_TABLE_NAME']

# Initialize AWS clients
dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table(DYNAMODB_TABLE_NAME)

def lambda_handler(event, context):
    # Kafka triggers often send records in batches
    for topic, records in event.get('records', {}).items():
        for record in records:
            try:
                # Decode the message value from Base64 and load its JSON content
                message_value_str = base64.b64decode(record['value']).decode('utf-8')
                message_body = json.loads(message_value_str)

                # 1. Extract the unique business identifier from the message payload
                transaction_id = message_body.get('INV_TXNS_STG_ID')

                if not transaction_id:
                    print("ERROR: Message is missing 'INV_TXNS_STG_ID'. Cannot deduplicate.")
                    continue

                print(f"Attempting to process transaction ID: {transaction_id}")

                # 2. Attempt a conditional write to DynamoDB to claim this ID
                # Set an expiration time (e.g., 7 days) for the record to be auto-deleted by TTL
                expiration_ts = int((datetime.now(timezone.utc) + timedelta(days=7)).timestamp())

                table.put_item(
                    Item={
                        'transactionId': str(transaction_id),
                        'processedAt': datetime.now(timezone.utc).isoformat(),
                        'expirationTime': expiration_ts
                    },
                    # This is the core of the deduplication logic. It fails if an item
                    # with the same 'transactionId' already exists.
                    ConditionExpression='attribute_not_exists(transactionId)'
                )

                # 3. If the write succeeded, it's a new transaction. Process it.
                print(f"SUCCESS: New transaction. Executing business logic for ID: {transaction_id}")
                execute_business_logic(message_body)

            except ClientError as e:
                # 4. If the conditional check failed, it's a duplicate.
                if e.response['Error']['Code'] == 'ConditionalCheckFailedException':
                    print(f"DUPLICATE DETECTED: Transaction ID {transaction_id} already processed. Skipping.")
                    # Gracefully exit without error
                else:
                    # Re-raise other DynamoDB errors
                    print(f"ERROR: A DynamoDB error occurred: {e}")
                    raise e
            except Exception as e:
                print(f"ERROR: An unexpected error occurred while processing the record: {e}")
                raise e

def execute_business_logic(message):
    """
    This is a placeholder for your actual processing logic.
    For example: insert a record into a database, call another service, etc.
    """
    print("Executing the main business logic...")
    # --- ADD YOUR BUSINESS LOGIC HERE ---
    pass

  FrequentMonitorLambda:
    Type: AWS::Lambda::Function
    DependsOn: MonitoringLambdaRole
    Properties:
      FunctionName: cosmos-frequent-file-monitor
      Handler: index.lambda_handler
      Runtime: python3.12
      Role: !GetAtt MonitoringLambdaRole.Arn
      Timeout: 60
      Environment:
        Variables:
          SNS_TOPIC_ARN: !Ref AlarmSnsTopicArn
          PRIMARY_NAMESPACE: !Ref PrimaryNamespace
          METRIC_NAME: !Ref SharedMetricName
      Code:
        ZipFile: |
          import boto3
          import os
          from datetime import datetime, timedelta, timezone

          SNS_TOPIC_ARN = os.environ['SNS_TOPIC_ARN']
          PRIMARY_NAMESPACE = os.environ['PRIMARY_NAMESPACE']
          METRIC_NAME = os.environ['METRIC_NAME']
          
          CHECKS_CONFIG = {
              'WID': { 'threshold': 1700, 'period': 900, 'dimension': {'Name': 'TagId', 'Value': 'WID'}, 'check_window_utc': None },
              'SPR_SKU': { 'threshold': 1, 'period': 900, 'dimension': {'Name': 'TagId', 'Value': 'SPR_SKU'}, 'check_window_utc': (11, 18) },
              'SPR_STORE': { 'threshold': 1, 'period': 900, 'dimension': {'Name': 'TagId', 'Value': 'SPR_STORE'}, 'check_window_utc': (11, 18) }
          }
          cloudwatch = boto3.client('cloudwatch')
          sns = boto3.client('sns')

          def lambda_handler(event, context):
              now_utc = datetime.now(timezone.utc)
              print(f"Running frequent checks at {now_utc.isoformat()}")

              for name, config in CHECKS_CONFIG.items():
                  if config['check_window_utc']:
                      start_hour, end_hour = config['check_window_utc']
                      if not (start_hour <= now_utc.hour < end_hour):
                          print(f"Skipping '{name}' check outside of its active window.")
                          continue
                  
                  print(f"Performing check for '{name}'...")
                  process_check(name, config, now_utc)
              
              return {'statusCode': 200, 'body': 'Checks complete.'}

          def process_check(name, config, now_utc):
              response = cloudwatch.get_metric_data(
                  MetricDataQueries=[{
                      'Id': 'm1',
                      'MetricStat': {
                          'Metric': { 'Namespace': PRIMARY_NAMESPACE, 'MetricName': METRIC_NAME, 'Dimensions': [config['dimension']] },
                          'Period': config['period'], 'Stat': 'Sum'
                      }, 'ReturnData': True,
                  }],
                  StartTime=now_utc - timedelta(seconds=config['period']), EndTime=now_utc
              )
              
              values = response['MetricDataResults'][0]['Values']
              
              if not values:
                  message = f"ALERT: Service Stalled! No '{name}' data received in the last {config['period'] // 60} minutes."
                  subject = f"COSMOS ALARM: {name} Stalled"
                  print(message)
                  sns.publish(TopicArn=SNS_TOPIC_ARN, Subject=subject, Message=message)
              else:
                  latest_value = values[0]
                  if latest_value < config['threshold']:
                      message = f"ALERT: Low Throughput! '{name}' file count was {int(latest_value)}, which is below the threshold of {config['threshold']}."
                      subject = f"COSMOS ALARM: {name} Low Count"
                      print(message)
                      sns.publish(TopicArn=SNS_TOPIC_ARN, Subject=subject, Message=message)
                  else:
                      print(f"OK: '{name}' count was {int(latest_value)}, which is at or above the threshold.")

import boto3
import os

# List of the target DB Cluster Identifiers to stop
DB_CLUSTER_IDS = [
    'rds-pfs-database-nonprod-auroracluster-0063jcvmvyfl',
    'rds-pfs-stg-database-auroracluster-Omoiovj8pj5x',
    'rds-pfs-database-preprod-auroracluster-bob0jbkdvcei',
    'rds-pfs-database-prod-auroracluster-1nf83uupv3xg'
]

# Get the AWS region from the Lambda environment variables
REGION = os.environ.get('AWS_REGION')

def lambda_handler(event, context):
    """
    Stops the specified RDS Aurora DB clusters.
    """
    rds_client = boto3.client('rds', region_name=REGION)
    
    stopped_clusters = []
    error_clusters = []

    print(f"Starting process to stop RDS clusters: {DB_CLUSTER_IDS}")

    for cluster_id in DB_CLUSTER_IDS:
        try:
            # First, check the cluster's current status
            cluster_info = rds_client.describe_db_clusters(DBClusterIdentifier=cluster_id)
            status = cluster_info['DBClusters'][0]['Status']
            
            if status == 'stopped':
                print(f"Cluster {cluster_id} is already stopped.")
                stopped_clusters.append(f"{cluster_id} (already stopped)")
            elif status == 'available':
                # Only attempt to stop if the cluster is available
                rds_client.stop_db_cluster(DBClusterIdentifier=cluster_id)
                print(f"Successfully initiated stop for DB cluster: {cluster_id}")
                stopped_clusters.append(cluster_id)
            else:
                # Log if the cluster is not in a stoppable state
                print(f"Cluster {cluster_id} is not 'available' (current state: {status}). Cannot stop.")
                error_clusters.append(f"{cluster_id} (state: {status})")

        except Exception as e:
            error_message = f"Error processing cluster {cluster_id}: {str(e)}"
            print(error_message)
            error_clusters.append(f"{cluster_id} (error)")

    print("\n--- Summary ---")
    print(f"Processed successfully: {len(stopped_clusters)}")
    print(f"Encountered errors or non-stoppable states: {len(error_clusters)}")

    return {
        'statusCode': 200,
        'body': {
            'stopped_or_found_stopped': stopped_clusters,
            'errors_or_wrong_state': error_clusters
        }
    }

          import boto3
          import os

          RDS_REGION = 'eu-west-1'

          DB_CLUSTER_IDS = [
              'rds-pfs-database-nonprod-auroracluster-0063jcvmvyfl',
              'rds-pfs-stg-database-auroracluster-Omoiovj8pj5x',
              ##'rds-pfs-database-preprod-auroracluster-bob0jbkdvcei',
              ##'rds-pfs-database-prod-auroracluster-1nf83uupv3xg'
          ]

          def lambda_handler(event, context):
              rds_client = boto3.client('rds', region_name=RDS_REGION)
              stopped_clusters = []
              error_clusters = []
              print(f"Starting process to stop RDS clusters in region: {RDS_REGION}")
              for cluster_id in DB_CLUSTER_IDS:
                  try:
                      cluster_info = rds_client.describe_db_clusters(DBClusterIdentifier=cluster_id)
                      status = cluster_info['DBClusters'][0]['Status']
                      if status == 'stopped':
                          print(f"Cluster {cluster_id} is already stopped.")
                          stopped_clusters.append(f"{cluster_id} (already stopped)")
                      elif status == 'available':
                          rds_client.stop_db_cluster(DBClusterIdentifier=cluster_id)
                          print(f"Successfully initiated stop for DB cluster: {cluster_id}")
                          stopped_clusters.append(cluster_id)
                      else:
                          print(f"Cluster {cluster_id} is not 'available' (current state: {status}). Cannot stop.")
                          error_clusters.append(f"{cluster_id} (state: {status})")
                  except rds_client.exceptions.DBClusterNotFoundFault:
                      error_message = f"Error processing cluster {cluster_id}: DBClusterNotFoundFault. Verify the cluster ID and REGION ('{RDS_REGION}') are correct."
                      print(error_message)
                      error_clusters.append(f"{cluster_id} (not found in region)")
                  except Exception as e:
                      error_message = f"Error processing cluster {cluster_id}: {str(e)}"
                      print(error_message)
                      error_clusters.append(f"{cluster_id} (error)")
              print("\n--- Summary ---")
              print(f"Processed successfully: {len(stopped_clusters)}")
              print(f"Encountered errors or non-stoppable states: {len(error_clusters)}")
              return {'statusCode': 200, 'body': {'stopped_or_found_stopped': stopped_clusters, 'errors_or_wrong_state': error_clusters}}
